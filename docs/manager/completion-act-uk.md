# Акт приймання-передачі наданих послуг

1. Відкрийте потрібний наряд-замовлення.
2. Перевірте клієнта, автомобіль, роботи, запчастини, дату рахунку та підсумок.
3. Натисніть «Зберегти» й дочекайтеся збереження. Поки є незбережені зміни, формування акта недоступне.
4. Відкрийте меню «Інші дії» (три крапки) → «Акт наданих послуг (PDF)».
5. Перевірте попередній перегляд і завантажте або надрукуйте документ.

Акт щоразу формується з поточних збережених даних наряду. Номер береться з номера наряду/рахунку, дата — з дати рахунку, а за її відсутності — з дати обслуговування. Документ містить роботи, запчастини, знижку за наявності, загальну суму й суму прописом для гривні, реквізити та місця для підписів. Підписи ставляться на роздруківці. Створення PDF не змінює стан оплати або виконання наряду.

У шаблоні немає вступного абзацу «Ми, що нижче підписалися…» з полями договору, а також блоку рекомендацій виконавця, зауважень замовника та наступного відвідування СТО. Артикул друкується поруч із назвою запчастини; відсутні в CRM бренд і УКТ ЗЕД не вигадуються.

## Як змінити реквізити

Відкрийте «Налаштування» → сторінку компанії (пряме посилання: https://crm.srv.lauto.com.ua/settings/company). У блоці «Реквізити виконавця для акта наданих послуг» змініть назву ФОП, код, юридичну адресу, телефон або банківські реквізити. Натисніть кнопку збереження даних компанії.

Зміни застосуються до наступного формування PDF, зокрема для старих нарядів. Уже завантажені PDF не змінюються: зберігайте підписаний примірник окремо. Ці реквізити відокремлені від адреси й телефону майстерні.
