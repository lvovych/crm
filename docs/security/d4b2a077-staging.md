## Знайдена проблема та виправлення

Перший запуск зупинився через заповнений диск локального Docker. Видалено лише конкретний відтворюваний кеш попередньої збірки цього завдання (`s7jx7uu62t0zg4clm5tcbuwgg`, 2,472 GB); образи й дані інших проєктів не видалялися. Після цього оригінальний образ успішно запустився.

Ця ситуація виявила помилку `init-db.sh`: будь-який збій `prisma migrate deploy` приховував stderr і запускав створення таблиці міграцій під повідомленням «Existing database detected». Тепер початкова діагностика зберігається, а legacy-шлях дозволено лише для явної помилки `P3005`. Інші помилки зупиняють запуск із початковим кодом завершення, без спроби змінити таблицю міграцій.

Регресійні тести `python3 scripts/test-init-db.py` пройшли: успішний запуск, P3005, брак місця, недоступна база та невдала попередня міграція. `bash -n init-db.sh` пройшов. Окремий реальний контейнер із навмисно неправильними локальними credentials повернув P1000, зберіг діагностику й не запускав fallback або застосунок.

## Перевірка виправлення

Образ `crm-local-staging:d4b2a077-startup-fix`, ID `sha256:a7018c9bfc0bf971e3d546915c7b788702d712828605627c300a3b9e4492c35a`, побудовано поверх оригінального образу з єдиним додатковим шаром, який замінює `/app/init-db.sh`. Перевірено незмінність базових шарів і runtime-конфігурації та побайтовий збіг entrypoint із виправленням. Повну компіляцію застосунку повторно не запускали: код застосунку та залежності не змінювалися.

Після виправлення обидва браузерні сценарії повторно пройшли за 1,2 хвилини. Повторний запуск entrypoint із 94 застосованими міграціями також успішний.

Віртуальний authenticator Chromium перевіряє реальний WebAuthn-протокол і серверні підписи, але не фізичний Touch ID/YubiKey, синхронізацію ключів, Safari чи зовнішній OAuth. Reverse proxy сервера до цього локального прогону не входить.

Після перевірки staging-контейнери й синтетичні volumes видалено, одноразовий env-файл прибрано. Обидва перевірені образи залишено локально. Push і розгортання на сервер не виконувалися.
