# Локальна перевірка складського модуля

Адреса: http://localhost:3097/stock-ledger?view=overview

Демонстраційний користувач: `demo@lauto.test`, пароль `DemoLedger!2026`.
Це спеціально створений локальний обліковий запис власника, без доступу до production.
Організація: «LAUTO — локальна демонстрація». Дані синтетичні; створювати й змінювати документи безпечно.

```sh
docker compose -f docker-compose.ledger.yml -f docker-compose.ledger.dev.yml up -d --no-build
```

Потрібен уже зібраний базовий образ `crm-ledger-acceptance-app`. Dev override підключає поточні `src`, `messages`, Prisma-схему й конфігурацію тільки для читання. Зміни вихідного коду підхоплюються автоматично. Перше відкриття нового екрана може бути повільнішим через компіляцію.

Залишаються окремі Docker volumes тестової PostgreSQL та вкладень. Не використовуйте `down -v`, якщо потрібно зберегти введені під час перевірки дані. Локальна production-копія для репетиції міграцій не підключена до цього застосунку.

Для повторного відкриття достатньо запустити Docker Desktop і виконати команду вище. Для зупинки зі збереженням даних:

```sh
docker compose -f docker-compose.ledger.yml -f docker-compose.ledger.dev.yml stop
```

Почніть із залишків, картки постачальника та наряду `DEMO-001`. У ньому фільтр зарезервовано, а гальмівні колодки потребують закупівлі. Є проведена накладна з боргом постачальнику та демонстраційна каса для перевірки оплат.
